# 凹分检定：预期序列与判定规则

状态：规则已和用户商定（2026-10-28）。已实现：
- 预期序列的文本格式和解析：`src/AxisRecognizer.Core/ExpectedSequence.cs`；
- 序列文件：`src/AxisRecognizer.Core/SequenceFiles.cs`，保存为 `axis-data/sequences/<名称>.txt`（UTF-8），供自动操作的程序读取；
- 启动器的“凹分序列”页：边输入边检查格式，可以打开、保存和另存。

还没做：从攻略视频识别出序列、实战识别和判定。

## 用途和分工

- 检定只用来决定这一次凹分要不要重开。
- 模拟操作和重开由用户的队友负责。本工具负责两件事：
  1. 从攻略视频识别出预期序列；
  2. 实战时自己截取游戏窗口，逐步和预期序列比对，每步输出一行 JSON 判定，供队友的程序读取。
- 只读取屏幕画面，不读游戏内存，不注入游戏进程。

## 序列里记什么

- 一份序列对应一整场战斗：从"战斗开始"到结算画面。混沌回忆的上下半场之间算一次换波。
- 只记我方单位：角色、忆灵、召唤物、特殊单位（如阿哈时刻）。敌方行动全部去掉，用右下角的"敌方单位行动中"/"我方行动中"文字区分。
- **主轴行动** `n`：本段第 n 次主轴行动。被控制跳过的回合也算。
- **额外行动** `n-i`：终结技就是额外行动，挂在被它打断的主轴行动 n 下面。连续释放的终结技都算同一次主轴行动的额外行动。
  - 例：长夜月主轴行动 n 中，昔涟的终结技进入当前格但还没放，又按下另一个角色的终结技，就依次是 n-1、n-2。
  - 本段第一次主轴行动之前的额外行动写成 `0-1`、`0-2`……
  - 画面依据：额外行动格左侧是小叉号，主轴行动格左侧是小点。
  - 额外回合不能算作普通（主轴）行动。
- **特殊行动** `== 换波 ==`、`== 转阶段 ==`：之后序号从 1 重新开始。
- **招式和目标**：从攻略视频识别后填上，用户可以修改纠正，不参与判定。
  - 招式：普攻、战技、终结技。
  - 目标（主目标）有两种写法，可以混用：
    - 从左数：`敌1`、`敌2`……，换波或有敌人倒下后，按当时场上的位置重新数；识别默认用这种。
    - 以 boss 为基准：boss 是 `敌(0)`，左边一个是 `敌(-1)`，右边一个是 `敌(+1)`，再往外是 ±2……，主要给用户自己修改用。没有 boss、或者有多个 boss 时只用从左数的写法。
  - 我方目标：`我1`、`我2`……，从左数（画面表现待从视频学习）。

## 判定

- 和预期序列相比，多了、少了、顺序反了，或者行动类型（主轴、额外、特殊）不对，都判**失败**。
- 结算时序列还没走完，或者序列走完后又出现行动，也判失败。
- 用户写了 `@` 条件的步骤，还要读轮次和剩余行动值；不在区间内判失败。没写的步骤只比对顺序。
  - 在这一步行动进行中读取（行动中行动值不变）。
  - 换波、转阶段默认不读行动值，写了 `@` 才读。
- 看不清、拿不准时判**待定**，不判失败（宁可不重开）。
- 每步判定在这一步出现后 1 秒内给出。
- 判失败或待定之后继续看画面，下次检测到"战斗开始"就从第 1 步重新比对。
- 以后可以加：连续失败很多次后录一段视频，供用户调整。

## 文本格式

```
# 第1波                                  ← # 后面是注释
1 长夜月
2 昔涟 战技 敌2      @ 轮次=1 行动值=120~160
2-1 长夜月 终结技
2-2 风堇 终结技 我3
3 记忆主 普攻 敌(-1)
== 换波 ==
1 昔涟 敌(0)        @ 轮次=2 行动值=200~260
== 转阶段 ==  @ 行动值=50~100
1 U0003 敌(+1)
```

- 一行一步，写成 `序号 单位 [招式] [目标] [@ 条件]`，各项用空格隔开；方括号表示可以不填。招式和目标的顺序随意。
  - 目标不写箭头（`敌2`，不是 `→敌2`）。不填目标就是游戏默认选中的目标。
- 单位写名称或 U 编号（旧编号也行，合并过的会跟到现在的编号）。以下情况会报错：知识库里没有这个名称、一个名称对应多个单位、写了敌方单位或非行动条目。
- 条件：`轮次=1`、`轮次=1~2`、`行动值=120~160`、`行动值=150`，两项都可以省略其中一项。
- 全角的 （）＝～＠＋－ 和全角数字都认。早期带箭头的写法（`→敌2`、`->敌2`）仍然能读，保存时按不带箭头的写法输出。
- 解析不会中断：每个问题都标出行号，分**错误**（改好前不能用于检定）和**提醒**（允许，但可能写错）两类。
  - 错误：序号不连续、额外行动没挂在当前主轴行动下、换段后没从 1 开始、看不懂的写法、区间下限大于上限、条件重复、没有任何行动等。
  - 提醒：主轴行动写了终结技、额外行动写了普攻或战技、某一段没有行动。
- 场上敌人数量要等识别到画面后才知道，所以"目标超出场上敌人数量"在纯文本里查不出来，留到实战和视频识别时再提示。
