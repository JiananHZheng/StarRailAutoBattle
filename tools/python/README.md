# 星穹铁道 开战前自动操作脚本 (Python)

独立于 C# 启动器的小脚本，用于大世界进战前的自动操作。两者互不依赖。

## 效果

在大世界里，脚本把"进战前的重复操作"自动做完：

1. （可选）启动游戏，或识别已运行的游戏窗口，并切到前台
2. 等待角色进场（模板匹配 `enter.png`，或手动按 `F8`）
3. 按住 `W` 前进，画面不再变化（撞墙）后自动松开
4. 按设定的顺序切换角色，按勾选释放秘技（`E`），最后按设置决定是否普攻进战
5. 每个操作之间间隔 1 秒，窗口左下角的状态栏会实时显示当前步骤

### 操作序列示例

| 顺序 | 释放秘技的角色 | 普攻进战 | 实际执行的操作 |
|---|---|---|---|
| 1234 | 无 | 是 | 切1 → 切2 → 切3 → 切4 → 鼠标左键 |
| 2134 | 1、3、4 | 是 | 切2 → 切1 → **E** → 切3 → **E** → 切4 → **E** → 鼠标左键 |
| 2134 | 1、3、4 | 否 | 切2 → 切1 → **E** → 切3 → **E** → 切4 → **E** |
| 4321 | 4 | 否 | 切4 → **E** → 切3 → 切2 → 切1（最后角色无秘技、不普攻，无额外操作） |

最后一个角色的四种情况：

| 释放秘技 | 普攻进战 | 操作 |
|---|---|---|
| 是 | 是 | `E` → 鼠标左键 |
| 否 | 是 | 鼠标左键 |
| 是 | 否 | `E` |
| 否 | 否 | 无 |

### 状态栏提示流程

正常运行时，状态栏依次显示：

```
正在启动游戏(如弹出 UAC 请确认)...      （仅勾选"先启动游戏"时）
已找到游戏窗口，切到前台...
等待进场检测(模板匹配)...  F9停止
按住 W 前进中...
已无法前进，松开 W
切换到角色2 → 角色1 释放秘技(E) → ... → 鼠标左键普攻进战
全部完成 ✔
```

### 安全保护

- 每次按键前都确认游戏在前台；若不在前台，会尝试切回并最多等待 10 秒，仍不在则**中止**，避免按键发到别的窗口
- 只截取游戏画面区域做检测，不受其他窗口影响
- 按住 `W` 最长 20 秒；`F9` 随时紧急停止并松开 `W`

## 使用

```powershell
pip install -r tools/python/requirements.txt
python tools/python/star_rail_auto.py
```

- 必须**以管理员身份**运行（游戏本体要求管理员权限，否则按键发不进去）
- 游戏建议窗口化或无边框全屏
- `F8`：手动触发"已进场"（没有 `enter.png` 时使用）　`F9`：紧急停止
- 可选：把角色进场时的 HUD 小图标截图保存为 `enter.png`，放在运行目录，分辨率需与游戏一致
- 按键约定：数字键 1~4 切换角色，`E` 释放秘技，鼠标左键普攻

## 注意

- 游戏路径不会保存，每次启动需重新填写
- Windows 不允许读取游戏进程路径时，窗口会找不到
- "无法前进"的检测阈值（`STUCK_DIFF_THRESHOLD`、`STUCK_COUNT`）可能需要按你的场景调整
- 米哈游用户协议不允许使用第三方自动化工具，使用有账号风险
