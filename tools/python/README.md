# 星穹铁道 开战前自动操作脚本 (Python)

独立于 C# 启动器的小脚本，用于大世界进战前的自动操作。两者互不依赖。

## 功能

- 可选：启动游戏(`.exe` / `.lnk`)，或只识别已运行的游戏窗口，并切到前台
- 检测角色进场后按住 W，画面不再变化(撞墙)后松开
- 按设定顺序切换角色，按规则释放秘技、用普攻进战，每步间隔 1 秒
- 只截取游戏画面区域做检测；每次按键前确认游戏在前台

## 使用

```powershell
pip install -r tools/python/requirements.txt
python tools/python/star_rail_auto.py
```

- 必须**以管理员身份**运行(游戏本体要求管理员权限，否则按键发不进去)
- 游戏建议窗口化或无边框全屏
- `F8`：手动触发"已进场"(没有 `enter.png` 时使用)　`F9`：紧急停止
- 可选：把角色进场时的 HUD 小图标截图保存为 `enter.png`，放在运行目录，分辨率需与游戏一致

## 操作规则

- 非最后一个角色：(勾选秘技则按 E)，再按数字键切到顺序中的下一个角色
- 最后一个角色：
  - 秘技 + 普攻进战：E → 鼠标左键
  - 无秘技 + 普攻进战：鼠标左键
  - 秘技 + 非普攻进战：E
  - 无秘技 + 非普攻进战：无操作

## 注意

- 游戏路径不会保存，每次启动需重新填写
- Windows 不允许读取游戏进程路径时，窗口会找不到
- 米哈游用户协议不允许使用第三方自动化工具，使用有账号风险
